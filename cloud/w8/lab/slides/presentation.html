Điều gì xảy ra khi terraform apply

aws Provision hạ tầng

  • VPC · 2 subnet · IGW · route
  • 2 Security Group (ALB, EC2)

  • App sẵn sàng sau ~3–5 phút
01 — Architecture
≥2 Provider · quyết định thiết kế

Vì sao provider thứ 2 là random?

Provider 1: aws

Tạo VPC, subnet, security group, IAM, EC2, ALB, target group và listener.

Provider 2: random

Tạo suffix unique để tên ALB, target group và IAM role không bị trùng khi apply lại hoặc chạy song song.

resource "random_id" "suffix" { byte_length = 4 } resource "aws_lb" "this" { name = "${var.name}-alb-${random_id.suffix.hex}" } # output của random → input của aws: 2 provider chung 1 dependency graph
Design decision
Bảo mật

SSM Session Manager — không SSH, không port 22

❌ SSH truyền thống

  • Mở port 22 ra Internet → attack surface
  • IP đổi liên tục phải sửa SG
  • Phải quản SSH key

✅ SSM Session Manager

  • EC2 chỉ cần outbound 443 + IAM role
  • KHÔNG mở inbound port nào
  • Vào máy qua IAM, audit qua CloudTrail
